# Kids Flight Games

Offline-first games for kids to play on flights. Each game is a standalone PWA that works without internet after first load.

**Play now:** [https://ectsang.github.io/kids-flight/](https://ectsang.github.io/kids-flight/)

## Games

| Game | Ages | Description |
|------|------|-------------|
| [Animal Tap Parade](animal-tap-parade/) | 2-4 | Tap animals to hear sounds, see animations, and play matching games |
| [Little Learners](little-learners/) | 2-5 | Five learning worlds: shapes, letters, colors, numbers, and patterns |
| [Sky Pilot](sky-pilot/) | 2-6 | Tap to fly through the sky, collect stars, dodge clouds |
| [Bubble Pop Tower](bubble-pop-tower/) | 4+ | Physics-based bubble matching puzzle with combos and powerups |

## Features

- Works offline after first load
- No ads, no tracking, no external dependencies
- Touch-friendly for tablets and phones
- Installable as home screen apps (PWA)
- Designed for airplane use

## Adding Games

Each game lives in its own subdirectory with a self-contained `index.html`. Add a new folder and link it from the root `index.html`.
